# Youtube URL share
Extension that simplifies `video` and `shorts` url sharing by removing unnecessary parameters.

![image](./image.png)

[![firefox](https://img.shields.io/badge/Firefox-141e24.svg?&style=for-the-badge&logo=firefox-browser&logoColor=white&color=272727)](https://addons.mozilla.org/en-US/firefox/addon/youtube-url-share/)

## How to build
### My environment:

* `NodeJS` v26.12.1
* `npm` 12.2.1
* `Cachy OS`

### Steps:
1. `npm ci`
2. `npm run zip:firefox` or `npm run zip:chrome`
3. look in `./.output/`
